# BacaIn
Teleprompter overlay untuk bikin konten (TikTok/Reels/YouTube Shorts).

## Cara dapat APK (paling gampang)
1. Upload semua isi folder ini ke repo GitHub baru (branch `main`).
2. Tunggu ±5 menit, GitHub Actions otomatis build.
3. Buka tab **Releases** di repo -> download `BacaIn.apk` -> install di HP.
